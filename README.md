# Rainfall Prediction Analysis Using Linear Regression and Random Forest Regression

## Project Overview
Proyek ini merupakan bagian dari kegiatan Praktik Kerja Lapangan (PKL) di **BMKG Maritim Tanjung Perak Surabaya**. Tujuan utama dari proyek ini adalah membangun dan membandingkan performa model algoritma Machine Learning (**Linear Regression** dan **Random Forest Regression**) dalam memprediksi curah hujan harian berdasarkan variabel meteorologi dari data historis tahun 2022 hingga 2026.
