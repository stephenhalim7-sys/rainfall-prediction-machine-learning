# Rainfall Prediction Analysis Using Linear Regression and Random Forest Regression

## Project Overview
This project was conducted as part of an internship program at **BMKG Maritim Tanjung Perak Surabaya**. The main objective is to build and evaluate Machine Learning regression models (**Linear Regression** and **Random Forest Regression**) to predict daily rainfall intensity using preprocessed historical meteorological data from 2022 to 2026.
